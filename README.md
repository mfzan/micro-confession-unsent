A tiny program that writes one unsent micro-confession to `/output/entry.txt`: a `To:` line naming the professor who wrote the writer's recommendation letter, then the message itself on a single line, exactly as typed — admitting the scholarship was won by guessing C, B, A on the last three exam questions, typed four times and deleted four times, because telling the truth means disappointing the one person who believed in them.

## Run it

```sh
python3 main.py
```
